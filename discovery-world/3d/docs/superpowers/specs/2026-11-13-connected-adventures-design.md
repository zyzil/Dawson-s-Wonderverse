# Connected adventures: approved design

The user approved one combined release implementing both recommendation sets, with no reading required for a five-year-old. Extend the existing offline Three.js game, preserve all existing features and saves, and use shared rendering resources and streamed districts.

Include optional guided Fluffkin rescue with movement/interaction demonstrations; contextual paw prompts; companion-home adventure; learning outcomes that restore rainbow decorations, grow a garden, and start a train display; persistent home souvenirs, paintings and building displays; a picture/voice discovery book with sea creature facts and silhouettes; companion reactions; distinct farm harvesting, woodland sound searches, snow-friend building, lab experiments and art gallery activities; separate Seaside beach play and Pier wildlife/fishing/treasure play; Pier Explorer with tide-pool discovery, fish catch, beach clue and treasure; varied bounded catches and wildlife surprises; illustrated map destinations; forgiving controls; separate audio settings; calm/reduced-motion options.

No losing, deadlines, purchases, ads, accounts or compulsory progression. Every activity remains playable independently. Adventure-critical rewards must not depend on luck. Existing players keep pets, gems, crown, wand, Fluffkins, paintings, builds and learning progress. New data uses optional validated fields in the existing save. Essential prompts have pictures and replayable speech; sound clues have visual equivalents. New 3D objects reuse materials and streaming to avoid new shaders or far-away update costs.

Validate saved-state migration, adventure sequencing and duplicate rewards, feature integration, small-screen layout, browser screenshots, required full smoke suite and before/after desktop software-rendering performance.
